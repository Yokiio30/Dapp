# My Dapp

Mobile-friendly wallet Dapp (connect, view balance, send ETH, sign message). Single static file, no build step.

## Deploy on Render
1. Push this folder to a GitHub repo.
2. Render dashboard > New > Static Site > pick the repo.
3. Build command: (leave empty) | Publish directory: `.`
   (Or New > Blueprint, which reads render.yaml.)
4. Open the `https://xxx.onrender.com` URL.

## Use on phone
Open the Render URL inside the MetaMask app's browser (or Trust Wallet / Coinbase Wallet browser).
On a normal phone browser, tap "Open in MetaMask app".
